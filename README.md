# أداة دراسة المنافسين — يلا سوا

أداة Python/Streamlit لدراسة تطبيقات وخدمات النقل المنافسة قبل إطلاق مشروع مشاركة المقاعد «يلا سوا».

## الوضع الحالي

هذه أول خطوة من التنفيذ. تم تجهيز:

- واجهة Streamlit عربية RTL.
- بحث أولي عن التطبيقات عبر `google-play-scraper`.
- حفظ المنافسين في SQLite.
- جداول منفصلة للمنافسين والمراجعات والرؤى.
- وحدات مستقلة للتنظيف، المشاعر، والتقارير Excel.
- هيكل قابل لإضافة جمع المراجعات والتحليل بالذكاء الاصطناعي لاحقًا.

## التشغيل

```bash
cd /home/ubuntu/yalla-sawa-market-tool
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
streamlit run app.py
```

ثم افتحي الرابط الذي يظهر في الطرفية، غالبًا `http://localhost:8501`.

## هيكل المشروع

```text
app.py                 واجهة Streamlit
src/config.py          الإعدادات والمسارات
src/db.py              SQLite والجداول والاستعلامات
src/scraper.py         البحث وجمع بيانات Google Play
src/analysis.py        تنظيف النصوص والمشاعر والموضوعات
src/reports.py         تصدير ملفات Excel
data/                  قاعدة البيانات والبيانات المحلية
exports/               التقارير الناتجة
tests/                 الاختبارات
```

## الخطوات التالية

1. جمع 150–300 مراجعة لكل تطبيق مع pagination وretry.
2. تحسين دعم اللغة العربية وتطبيع النصوص.
3. إضافة اختيار 2–4 منافسين فقط للتحليل.
4. بناء الرسوم البيانية ومقارنة التقييمات والشكاوى.
5. إضافة تقرير Excel متعدد الصفحات.
6. إضافة ملخص فجوات السوق وتوصيات مشروع «يلا سوا».
